# Changelog

## 0.1.0 (unreleased)

- 新增 DSH Web 虚拟伙伴插件。
- 提供 Three.js 3D 透明浮空卡通仙女、拖拽移动、单击语音聊天和双击设置面板。
- 设置面板支持人物角色（贴心伙伴/知性学姐/元气少女/高冷御姐/软萌小猫）、人物皮肤、背景信息文本框、六种女声音色切换和流式实时回复开关。
- 优化聊天反馈：右上角显示 🤔，不显示说话文字；说话时人物放大 1.2 倍并恢复；模型不再持续旋转。
- 实时优化：新增 `/virtual-companion/chat/stream` SSE 按句流式回复，客户端边生成边朗读，降低聊天等待感。
- 实时优化：SSE 增加 token 增量即时上屏，新增 `GET /virtual-companion/tts/stream` 流式 MP3，`msedge-tts` 边合成边播放，不再等整句音频缓冲完成。
- 置顶优化：虚拟人物浮层固定视口并使用最高 `z-index`，始终保持在 DSH 页面最上层。
- 只保留“人物”一个模型，移除模型切换面板。
- 单击人物后模型主动提问，用户语音回答，形成连续语音对话。
- 语音优化：弃用浏览器低质量 `speechSynthesis`，改为 Host 通过开源 `msedge-tts` 调用 Microsoft Edge 神经网络语音合成中文语音。
- 站姿修复：默认站姿改为古风「敛手而立」——大臂自然下垂、肘微屈于身体两侧，双手在小腹前轻叠（右手轻搭左手）；IK 改为肘圆闭合解（单帧收敛，不再摆荡），目标经姿态空间矩阵变换，去除身高归一化缩放对手位的干扰。
- 抖动修复：肘极点由世界空间改为模型空间（相对肩部），模型转到 ~86.5° 附近时不再因世界 x 符号翻转而每帧跳到身体另一侧（胳膊持续抖动）。新增真实 PMX 多偏航无振荡回归测试。
- 新增 4 个可用模型：薇薇安（绝区零）、金乌·毛绒派对（深空之眼）、Zankou·原皮、Zankou·皮肤2黑（异环）。模型文件仅存放于本地存储目录，不随包分发；新增模型加载回归测试（网格/骨架/IK 链齐全）。
- 手臂稳定性：默认敛手站姿改为解析 IK 单帧直接写回；上臂写回后刷新肘、腕世界矩阵再解前臂，消除跨帧追赶造成的来回抖动。回归测试扩展为同时覆盖双手与双肘，并校验骨架初始化后 5 帧内收敛。
- 手部微动：恢复双手随呼吸的轻微起伏（与躯干呼吸同相），不再静止钉在目标点；单帧解算保证不破坏收敛稳定。
- 放松站姿：新增 Blender 程序导出的「放松站姿」VPD（models/motions/放松站姿-&lt;id&gt;.vpd，Shift-JIS 姿势数据），加载模型后自动应用——大臂贴身下垂（叉开 51°→0°）、肘在肩正下方、双手在小腹前自然轻拢，手腕带呼吸微摆；VPD 缺失时静默回退 IK 敛手站姿。新增回归测试验证解析与应用后手臂几何。
