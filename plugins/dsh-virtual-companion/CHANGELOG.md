# Changelog

## 0.1.1 - 2026-08-22

### Added
- 模型列表接入 6 个新模型：幽兰黛尔·完美假日、胧嫣·瑞狐 珠光曳影、芬妮·辉耀 疾速耀星、雷之律者（芽衣）、红蔷薇·舞者（长裙/短裙）。模型文件按版权规则仅存放于本地存储目录，不随包分发。
- 说话口型跟随语音：表情 VMD 的循环口型/眨眼轨道在说话时不再覆盖程序口型（此前每帧被 表情.vmd 轨道覆盖，嘴不受音量控制）；音量包络平滑（快攻慢放），安静时轻微张合、语句停顿处闭嘴；口型候选从标准 あいうえお 扩展兼容中文模型的常见嘴型名（□/口/ワ/ん/ω/あ２ 等），「う」缺失等非标 morph 模型同样能动嘴。

### Changed
- 设置面板 UI 迁移 Reka UI 系组件（Radix 同源，与看板插件同一组件家族）：人物角色/人物模型/动作列表/音色由原生 `<select>` 改为 Radix Select——触发器聚焦后 ↑/↓ 键逐项选择，模型下拉每次按键即时重新加载场景模型；亮度/面部光/朝向由原生 range 改为 Radix Slider；「流式实时回复」checkbox 改为 Radix Switch。

## 0.1.0 (unreleased)

- 默认敛手站姿补齐手掌朝向约束：IK 落位后以「手腕→中指根」对齐双手共同指向，消除腕点正确但手指镜像交叉成 X 形的问题；同时兼容 MMD 全角数字骨骼名，恢复手指自然微弯。
- ~~默认姿势统一烘焙（3° 臂下垂）~~：已回退（2026-08-20，用户要求）。`scripts/bake-default-pose.py` 保留为工具，`models/_pose-backup-20260819/` 备份保留；14 个 `models/*/model.pmx` 已全部恢复为原文件（49°~55° 臂展）。
- 新增 DSH Web 虚拟伙伴插件。
- 提供 Three.js 3D 透明浮空卡通仙女、拖拽移动、单击语音聊天和双击设置面板。
- 设置面板支持人物角色（贴心伙伴/知性学姐/元气少女/高冷御姐/软萌小猫）、人物皮肤、背景信息文本框、六种女声音色切换和流式实时回复开关。
- 优化聊天反馈：右上角显示 🤔，不显示说话文字；说话时人物放大 1.2 倍并恢复；模型不再持续旋转。
- 实时优化：新增 `/virtual-companion/chat/stream` SSE 按句流式回复，客户端边生成边朗读，降低聊天等待感。
- 实时优化：SSE 增加 token 增量即时上屏，新增 `GET /virtual-companion/tts/stream` 流式 MP3，`msedge-tts` 边合成边播放，不再等整句音频缓冲完成。
- 置顶优化：虚拟人物浮层固定视口并使用最高 `z-index`，始终保持在 DSH 页面最上层。
- 只保留“人物”一个模型，移除模型切换面板。
- 单击人物后模型主动提问，用户语音回答，形成连续语音对话。
- 语音优化：弃用浏览器低质量 `speechSynthesis`，改为 Host 通过开源 `msedge-tts` 调用 Microsoft Edge 神经网络语音合成中文语音。
- 站姿修复：默认站姿改为古风「敛手而立」——大臂自然下垂、肘微屈于身体两侧，双手在小腹前轻叠（右手轻搭左手）；IK 改为肘圆闭合解（单帧收敛，不再摆荡），目标经姿态空间矩阵变换，去除身高归一化缩放对手位的干扰。
- 抖动修复：肘极点由世界空间改为模型空间（相对肩部），模型转到 ~86.5° 附近时不再因世界 x 符号翻转而每帧跳到身体另一侧（胳膊持续抖动）。新增真实 PMX 多偏航无振荡回归测试。
- 新增 4 个可用模型：薇薇安（绝区零）、金乌·毛绒派对（深空之眼）、Zankou·原皮、Zankou·皮肤2黑（异环）。模型文件仅存放于本地存储目录，不随包分发；新增模型加载回归测试（网格/骨架/IK 链齐全）。
- 手臂稳定性：默认敛手站姿改为解析 IK 单帧直接写回；上臂写回后刷新肘、腕世界矩阵再解前臂，消除跨帧追赶造成的来回抖动。回归测试扩展为同时覆盖双手与双肘，并校验骨架初始化后 5 帧内收敛。
- 抖动根治：个别模型 PMX 骨骼数组违反「父先子后」约定（如 mintswimsuit 的 ひじ 排在 腕捩 之前），Babylon prepare 按数组顺序组合时父终阵陈旧，肘部世界矩阵在两种不一致计算间逐帧摆动，IK 读取不可能几何后陷入多解轮转（双态/三态闪烁）。模型加载后强制父先子后重排骨骼数组根治。
- IK 收敛重构：骨架刷新统一由 Skeleton.prepare 负责（Babylon 9 的 bone.computeWorldMatrix 是空操作，逐骨骼刷新无效）——主循环每次修改骨骼后刷新、solveArm 每次写回后刷新；臂长 l1/l2 首帧冻结不再每帧重测；肘解改为固定极点半平面唯一解，删除「最近点 + 30° 拒绝」连续性约束（不再依赖上一帧状态，解间翻转不可能发生）。新增全部 14 个模型 10 秒站姿稳定性验收测试（无交替翻转、帧间位移≈0、肘在身体两侧、手朝小腹伸展）。
